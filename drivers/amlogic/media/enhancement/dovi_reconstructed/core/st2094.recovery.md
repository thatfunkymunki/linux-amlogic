Disassembly is retained in `../evidence/spatial_st2094_ghidra.json`.
The C implementation links real bitstream/alignment and extension-payload
readers, including the latter's actual five-register ABI. Its second argument
is the address of the decoder event slot, not the event function pointer.

The reader clears availability before parsing country/provider/user/type
gates, then parses refresh and extension records. It preserves byte truncation
of counts, index/count wrapping, level-3 PQ halving, level-2 to level-8 trim
conversion, optional level-10 append, and default level-254 append. The four
recognized target-PQ intervals retain the 16-bit modular comparison.
It writes only the original identity header/first-partition fields. Unsupported
identifiers return zero after their original reads and state changes.

The push wrapper returns -7 for a null decoder or a nonzero-size null input.
For a valid decoder, zero size succeeds without reading input. It binds the
empty payload, initializes the real bitstream, and returns a nonpositive reader
result unchanged or zero after a positive result.

`../tests/test_st2094.py` compares 1,005 calls: 354 direct reader calls,
647 push calls, and four argument edges. Both new bodies reach all instructions.
Tests cover all country bytes and extension levels, identifier combinations,
refresh/count truncation and wrap, recognized PQ boundaries, weight conversion,
default/explicit extension combinations, signed bit-count wrap and optional
event callbacks. Returns, ordered events, complete decoder/context/root/header/
payload/DM/input backing and surrounding guards are compared. Original
extension and bitreader instructions execute; kernel `_mcount`, `sprintf`,
`memset` and `memcpy` imports are explicitly modeled. The result JSON records
the exact coverage of these dependencies; this suite alone does not cover
every extension instruction.

The independent `../tests/review_st2094_callbacks.py` audit adds eight
calls with event-driven pointer/context/slot changes, count changes,
record-level re-reads, signed baseline wrap, and a conversion count wrapping
from 255 to zero. All match the original instructions and complete state.

This retains the original unchecked contract. Supply writable full decoder,
root, header, context, DM/extension and payload storage and readable padded
input. Overflow fixtures have expanded backing for the actual writes, including
the sentinel/append records. Main fixtures use recording event callbacks;
the independent audit covers the stated mutations. The evidence requires
disjoint backing. It does not prove nominal allocation safety
for malformed counts, arbitrary aliasing, races, module loading or playback.
